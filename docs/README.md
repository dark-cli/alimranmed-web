# Documentation index

Docs are split by audience. The **user manual** (`docs/user-manual/`)
is for the site owner, editor, or content writer — anyone who edits
content but doesn't touch code. The **developer** docs (`docs/dev/`)
cover the codebase, build pipeline, and deployment.

Start with the [top-level README](../README.md) for a one-screen overview.
